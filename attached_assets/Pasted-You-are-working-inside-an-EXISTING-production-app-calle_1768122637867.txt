STEP 7 — Risk Engine + Forecast Endpoint
------------------------------------------------------------
Risk calculation rules (based on TODAY in Africa/Johannesburg):
- If today > delivery_due_date AND delivered=false → OVERDUE
- Else if delivery_due_date is within 2 WORKING DAYS AND delivered=false → AT_RISK
- Else → SAFE

Capacity forecasting (global, not per retoucher):
- daily_capacity_projects from settings (default 3)
- Given a targetDate=YYYY-MM-DD:
  - projects_due_before_target = count of projects where delivery_due_date <= targetDate and delivered=false
  - available_capacity_before_target = (number of working days from tomorrow to targetDate inclusive) * daily_capacity_projects
  - feasible = available_capacity_before_target >= projects_due_before_target
  - at_risk_projects = list of projects where risk_level != SAFE (include id, client_name, delivery_due_date, risk_level)

Add endpoint (Admin + Sales + Lead + Data Wrangler):
- GET /api/shoottracker/forecast?targetDate=YYYY-MM-DD
Return:
{ targetDate, projects_due_before_target, available_capacity_before_target, feasible, at_risk_projects }

Also ensure risk_level is recalculated during sync and also recalculated whenever Delivered toggle changes (Step 9).
