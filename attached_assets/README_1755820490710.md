# Lyra – Prompt Optimizer (Local/Replit Pack)

This pack gives you **two ways** to use Lyra right now:
1. **Agent/System Prompt** – paste `system_prompt_lyra.txt` into your AI agent's system message.
2. **Local API (FastAPI)** – run a small service that turns rough briefs into optimized prompts.

---

## Quick Start (System Prompt)
1. Open your AI tool (ChatGPT custom instructions / system prompt, or your own agent).
2. Paste the full contents of `system_prompt_lyra.txt` as the **system message**.
3. Start your message with your rough task and specify **Target AI** + **Style (DETAIL/BASIC)**.

---

## Run the API (Replit or Local)

### Install
```bash
pip install -r requirements.txt
```

### Start the server
```bash
uvicorn app:app --reload --port 8080
```

### Call the API
```bash
curl -X POST http://127.0.0.1:8080/optimize \
  -H "Content-Type: application/json" \
  -d '{
    "user_prompt": "Write a landing page hero for a maternity photography studio in Johannesburg.",
    "mode": "DETAIL",
    "target_ai": "ChatGPT",
    "request_type": "creative",
    "audience": "Expecting moms aged 25–40 in South Africa",
    "tone": "warm, confident, elegant",
    "style": "poetic but concise",
    "output_format": "3 headline + subheadline options with a CTA line",
    "constraints": ["No clichés", "Localize to Johannesburg", "Max 60 words per option"]
  }'
```

### Response
Returns JSON with:
- `optimized_prompt` – your final, structured prompt
- `what_changed` – bullets of improvements
- `pro_tip` – usage advice
- `mode_used` – BASIC or DETAIL

---

## Files
- `system_prompt_lyra.txt` – drop‑in agent/system prompt.
- `optimizer.py` – core optimization engine.
- `app.py` – FastAPI service exposing `/optimize`.
- `requirements.txt` – dependencies.
- `examples/example_payload.json` – sample body for quick testing.

---

## Notes
- No external AI calls are made here. Lyra structures prompts for whatever model you send them to.
- You can wire this API in front of OpenAI/Claude/Gemini as a preprocessing step.
- Keep prompts under model context limits; for Claude use longer context wisely.
