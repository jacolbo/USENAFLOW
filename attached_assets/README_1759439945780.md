# Usena Flow — Custom Share Links Starter

Backend-only starter for per-client, per-folder (album) **custom links**: expiring, revocable, optional PIN, JWT-gated public access.

## Quickstart (Replit or local)

1) **Secrets / Env**
- `DATABASE_URL` = your Postgres (use dev DB)
- `JWT_SECRET` = random string
- `PUBLIC_BASE_URL` = `http://localhost:3000` (dev) or your domain

2) **Install**
```bash
npm i
```

3) **Migrate**
```bash
npm run migrate:share
```

4) **Run**
```bash
npm run dev
```

5) **Health**
```
GET http://localhost:3000/health
```

## Create a Custom Link
```bash
curl -X POST http://localhost:3000/galleries/<GALLERY_ID>/share-links   -H 'Content-Type: application/json'   -d '{"slug":"mbali-maternity-2025","allowDownload":false,"showWatermark":true}'
```

### Resolve (get JWT)
```bash
curl -X POST http://localhost:3000/public/resolve   -H 'Content-Type: application/json'   -d '{"slug":"mbali-maternity-2025","token":"<token-from-create>"}'
```

### Fetch public gallery JSON (stub)
```bash
curl -H "Authorization: Bearer <grant>" http://localhost:3000/public/galleries/mbali-maternity-2025
```

> This starter stubs image URLs; wire in your GCS signer later.
